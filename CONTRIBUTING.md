# Contributing to ZazuEMP

ZazuEMP is an owner-controlled proprietary project.

## Before contributing

Do not submit code, assets, documentation or data unless you have the right to provide them and they do not knowingly violate another party's rights.

Do not include secrets, personal information, confidential third-party material or unlicensed assets.

## Contribution process

1. Understand the current repository before changing it.
2. Keep changes focused and justified.
3. Preserve existing conventions unless there is evidence for change.
4. Add or update tests when behaviour changes.
5. Update documentation when repository reality changes.
6. Record material architectural or ownership decisions.
7. Verify the final change.
8. Keep unrelated cleanup out of focused changes.

## Ownership and licence

Submitting a contribution does not, by itself, transfer copyright ownership to the project owner.

Before a contribution is accepted where ownership or licensing is material, the project owner may require a separate written agreement covering assignment, licence, confidentiality and/or other rights.

Until such an agreement exists, contributors should assume their existing rights remain theirs and that no broad licence is granted merely by opening a pull request.

## Code review

A change is not considered complete merely because it has been committed. Review should establish:

- what changed
- why it changed
- what it affects
- what could break
- how it was tested
- what remains unverified

## Prohibited submissions

Do not submit:

- copied proprietary code without permission
- malware or intentionally harmful code
- credentials or secrets
- customer/private data
- unlicensed third-party assets
- knowingly deceptive or malicious changes
