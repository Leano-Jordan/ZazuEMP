## Loading rule

Load only the skill(s) relevant to the current target.

Do not copy their instructions into AGENTS.md, 00_DIRECTOR_ENGINE.md, or other master prompts unless a rule is truly global.

The skills complement the existing engines:

Director → chooses target and state
Specialist engine → executes bounded capability
Skill → supplies reusable workflow
Verification/Guardian → proves or challenges result
Director → reconciles and accepts

## Anti-bloat rule

The master prompt governs authority and invariants.
Skills govern reusable procedures.
References hold background knowledge.
Repository state holds current facts.

Do not turn the master prompt into a catalog of every procedure.
