## Reuse safeguards

- Attribution is published on the landing page's linked Image credits & licences page; each entry links to the source file and the CC BY-SA 4.0 licence.
- The photos are illustrative only. They do not depict confirmed Zazu customers or imply endorsement by the subjects, venues, event organisers or Wikimedia.
- The Content Security Policy and deployment audit permit remote image requests only to HTTPS upload.wikimedia.org paths below /wikipedia/commons/thumb/; no other remote image host is approved.
- The source files are not bundled into GitHub Pages. Images therefore require connectivity to Wikimedia's image host. This is an explicit trade-off from the earlier self-hosted image setup.
- Check each source page again before replacing or reusing a photograph. Licence terms can differ between files; preserve author, file-page and licence attribution, and do not assume all Wikimedia Commons imagery has the same licence.
- The source pages state CC BY-SA 4.0. The licence requires attribution and share-alike for adapted works; the page does not imply the licensors or pictured people endorse Zazu.
