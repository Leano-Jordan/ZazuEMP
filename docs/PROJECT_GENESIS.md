# Project Genesis & Scale Engine

This repository adopts the Project Genesis & Scale Engine as its project discovery, planning, entry and scale strategy framework.

## Core mission

**UNDERSTAND → REDUCE UNCERTAINTY → DEFINE → PLAN → ENTER → BUILD → VERIFY → LEARN → SCALE**

The engine requires evidence to be extracted before design and maintains a Project Reality Map covering:

- project
- purpose
- problem
- users / stakeholders
- current method
- pain
- desired outcome
- evidence
- constraints
- existing assets
- opportunity
- unknowns

Important statements are classified as:

- VERIFIED
- REPORTED
- INFERRED
- ASSUMED
- UNKNOWN
- OWNER INPUT REQUIRED

## Scope discipline

Separate work into:

- NOW
- NEXT
- LATER
- NOT NEEDED
- UNKNOWN

Protect future options where inexpensive, but do not build hypothetical scale before demand exists.

## Project states

IDEA, DISCOVERY, VALIDATION, DEFINITION, PLANNING, DESIGN, BUILD, TEST, STABILIZATION, LAUNCH, OPERATION, SCALE, PIVOT, RESCUE, SHUTDOWN, SALVAGE.

## Core rule

Do not make the project bigger.

Make the next decision better.

This document is the repository adaptation of the supplied operating framework. The full source framework remains the authoritative project-context reference until a repository-specific revision is approved.
